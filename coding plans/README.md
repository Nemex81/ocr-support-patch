# Coding Plans

Questa cartella raccoglie i documenti di pianificazione tecnica del progetto.

Serve per definire in anticipo cosa fare, come farlo e con quali vincoli,
prima di intervenire sui file della patch o sugli strumenti di supporto.

## Utilità della cartella

- progettare modifiche strutturate prima dell'implementazione
- pianificare nuove codifiche o conversioni GUI
- organizzare revisioni tecniche e correzioni progressive
- documentare obiettivi, priorità, rischi e criteri di verifica
- mantenere una traccia chiara delle decisioni prese durante il lavoro

## Contenuti tipici

- piani correttivi
- strategie di implementazione
- checklist operative
- bozze di workflow
- note preparatorie per audit, review o refactor

## Quando usare questa cartella

Usare questa cartella quando il documento serve a guidare il lavoro futuro.
Se il file descrive cosa si intende fare, quali problemi risolvere e quale
approccio seguire, allora appartiene qui.

## Distinzione pratica

`coding plans` contiene documenti di progettazione e pianificazione.
I risultati, gli esiti delle verifiche e le analisi a posteriori vanno invece
conservati nella cartella `reports`.
